## Conventions

- **Desktop** : 1440 px de large, hauteur minimale 1024 px, page entière (les pages longues sont livrées en un seul PNG pleine hauteur).
- **Mobile** : 390 px de large, hauteur minimale 844 px.
- **Nommage** : `NN_NN_Nom_Ecran_Desktop.png` / `_Mobile.png` (dossier, numéro d’écran, nom).
- Le détail de chaque fichier (écran, format, dimensions) est dans `INDEX.csv`.

## Réalisation

Maquettes visuelles uniquement : aucune page web fonctionnelle n’est livrée. Les écrans ont été composés avec un outil de rendu interne puis exportés en PNG ; ce code n’est pas inclus.

## Limites à connaître

- Tous les contenus, noms, chiffres, organisations et références sont **fictifs**.
- Les coordonnées (domaine, téléphone, adresses) sont des **[placeholders]** à remplacer.
- Aucune photographie : illustrations vectorielles génératives sobres (carte d’Afrique en points, motifs géométriques).
- Icônes : bibliothèque Lucide (licence ISC).
- Les maquettes sont statiques : les états (vide, chargement, erreur, succès) sont présentés comme écrans ou planches distincts, sans prototype cliquable.
- Les PNG sont exportés en 1x ; pour du @2x ou un transfert vers Figma, un nouveau rendu est nécessaire.
- Contrôle qualité : dimensions et nommage vérifiés sur les 162 fichiers, relecture visuelle par planches-contact ; ce n’est pas une revue pixel par pixel de chaque écran.
